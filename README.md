## ✨ Project Overview

**ITZFIZZ — Digital Universe** transforms a simple hero section into an interactive digital experience.

The main visual element is a **sports car controlled by the user's scroll position**. Instead of using a time-based autoplay animation, the movement responds directly to scrolling, creating a smooth and interactive browsing experience.

The design combines:

- Scroll-driven motion
- Smooth entrance animations
- Animated statistics
- Interactive cursor effects
- Parallax movement
- Magnetic interactions
- Responsive layouts
- Modern dark UI
- Subtle digital effects

The goal was to create an experience that feels **dynamic, premium, and technology-focused** while keeping the implementation clean and lightweight.
